SignalEscrow: pay per signal, enforced by Bitcoin Cash

A subscriber locks BCH in a covenant. The signal provider can take a fixed price, at most once per interval, and only by publishing the signal's hash on chain. The subscriber can take everything back at any time. No server holds the money.

Source code Escrow on the chipnet explorer

This page shows the state of the project before BCH BLAZE 2026: two contracts, tests and a command-line run on chipnet. It has no app and no wallet connection yet. Work done during BLAZE is published separately.

How it works

1. DepositThe subscriber sends BCH to the escrow address. Price, interval and both parties are fixed in the contract.
2. ChargeOnce per interval, the provider takes exactly the price and writes the signal's sha256 into the same transaction.
3. Leave anytimeThe subscriber's signature alone returns everything that is left.
